# すいみん日誌（Sleep Diary）

日々の睡眠記録をつけることで睡眠の改善に役立てる、Next.js + Supabase 製の睡眠日誌 Web アプリです。スマホ・PC 両方の画面サイズに対応しています。

## 主な機能

- **ログイン・新規アカウント登録**（Supabase Auth メール／パスワード認証）
  - Row Level Security (RLS) により、各ユーザー自身の睡眠データのみ閲覧・編集可能
- **睡眠日誌の入力フォーム**
  1. 記録対象の日付
  2. 就寝時刻（寝床に入った時間）
  3. 入眠時刻（実際に眠りについた時間）
  4. 中途覚醒（途中で目が覚めて再び眠るまでにかかった時間・分）
  5. 目が覚めた時間
  6. 起床時刻（布団から出た時間）
  7. 熟睡感スコア（1：全くなし〜5：ぐっすり）
  8. 日中の支障度スコア（1：支障なし〜5：強い眠気）
  9. メモ（カフェイン・アルコール摂取、入浴時間、眠れなかった理由など）
- **自動計算サマリー（リアルタイム表示）**
  - 総臥床時間（TIB）
  - 実睡眠時間（TST）
  - 睡眠効率（SE）
  - 覚醒合計時間（入眠まで・中途覚醒・起床前の内訳付き）
- **ルールベースの改善アドバイス**
  - 睡眠効率・入眠潜時・中途覚醒・起床前滞在・実睡眠時間・スコア・メモ内容・直近7日間の起床リズムをもとに、CBT-I／睡眠衛生の知見に沿ったコメントを自動生成
- **グラフ・分析**
  - 直近7日／直近30日／全期間の切り替え＆平均KPI表示
  - 睡眠時間（TIB・TST）と睡眠効率（SE）の推移グラフ
  - 就寝〜起床の時間帯チャート（生活リズムのズレを可視化）
  - 熟睡感・日中の支障度スコアの推移グラフ
- **履歴一覧・編集・削除・CSVエクスポート**
  - 日付やメモによる検索、日別アドバイスの展開表示、過去記録の編集・削除
  - Excel で文字化けしない UTF-8 BOM 付き CSV エクスポート

## 起動方法

```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開くとログイン画面が表示されます。

## 環境変数

`.env.local` に Supabase の接続情報を設定しています（テンプレートは `.env.example` を参照）。

```env
NEXT_PUBLIC_SUPABASE_URL=...
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=...
```

## データベーススキーマ

マイグレーション SQL は `supabase/migrations/20261125000000_create_sleep_logs.sql` に保存されており、Supabase プロジェクト `sleep-diary` に適用済みです。
